# Project Profile

**Gabriel Voice OS** is a personal AI and voice-systems laboratory exploring secure integration between voice assistants, real-time AI services, WebRTC, containers and controlled tool execution.

## What this project demonstrates
- Node.js service architecture
- Voice-assistant and realtime interaction flows
- WebRTC integration
- Secret handling, encrypted history and authorization controls
- Containerization, CI and operational documentation

## Portfolio signal
The repository demonstrates systems-integration thinking across AI, voice, backend security and deployment operations.

**Domain:** AI Systems, Voice Interfaces, Application Security  
**Stack:** Node.js, WebRTC, Docker
