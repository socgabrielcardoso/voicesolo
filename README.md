# Gabriel Voice OS

Donna pela Echo Dot, com backend próprio e integração OpenAI.

Projeto em implementação. Uma Alexa Custom Skill encaminha intents e slots reconhecidos, não o áudio bruto do microfone. A experiência na Echo funciona por turnos. Voz contínua via OpenAI Realtime exige cliente de áudio próprio.

O repositório será atualizado com backend, skill pt-BR, segurança, testes e implantação. Nenhuma credencial deve ser incluída no Git.
